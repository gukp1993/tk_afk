# 五大页面背景 · 提示词 v1（主城/玩法/战役/英雄/背包）

> 背景与立绘的写法差异：立绘是"被看的主角"，背景是**被 UI 压在底上的氛围**。核心要求：够暗、对比柔、中部留白（卡片落位）、不抢前景。全部走水墨纸黄描金色系，与现有 UI（深墨绿底 #171009、纸黄卡、描金边）同调。

## 通用模板（换 {场景} 槽即可，其余一字不改）

```
手机卡牌游戏页面背景：{场景描述}。
风格：国风水墨淡彩，纸黄与描金色系点缀，氛围沉静古朴；
大色块平涂，柔和过渡，不堆描线细节。

画面中部大面积虚化留白（界面卡片落位区），上下边缘自然压暗成渐晕。
内容：全部元素做远景、中景剪影处理，无近景主体，无人物特写。
构图：竖版 9:16，目标 1080×1920 像素；
重要视觉元素避开顶部 12% 与底部 18%（状态栏与导航条落位）。
整幅即背景：无文字、无水印、无 logo、无边框、无底座。
避免：鲜艳高对比、密集纹样、近景大主体、人物特写、亮色或纯白底。
```

## 交付与自检

1. **自检法**：生成后把图调暗看中部 1/3——如果那里有抢眼的细节，重生成；UI 卡片会落在那。
2. **同批连生成**：五张一次会话连着出，色系氛围最统一。
3. **交付**：放进 `output/art/scenes-v1/`（命名 home / journey / campaign / heroes / bag），跟我说一声——背景装载层还没接代码，我来接（换掉纯色底 + 有图用图/无图回退）并实拍验收。
4. 压缩入包我处理（1080×1920 量化后每张预计 ~50-70KB，走立绘同一分包）。
