# Q 版武将立绘 · 提示词模板 v2（为什么 v1 怪 + 怎么改）

> 针对 v1（关羽-Q版立绘-v1）的诊断与修订。v1 的问题不在画工，在**风格错位**——按下面模板改，一致性还能覆盖全卡池 120 将。

## 一、v1 怪在哪（四个根因）

1. **头身比掉进恐怖谷**：「约三头身」不是 Q 版，是"缩小的成年人"。真 Q 版锚定 **2~2.5 头身**（头大身小、圆脸短手短腿），3 头身以上就会像 v1 这样：身子是手办、脸是大人，怎么看怎么别扭。
2. **写实脸 × Q 版身**：浓眉+丹凤眼+通红漆面脸+拖胸长髯，是写实戏曲脸谱的语言；装在短圆身体上就是"生气的玩偶"。红脸要保留，但必须**卡通化**：红润底色+高光+腮红，而不是全脸通红。
3. **细节过载**：鳞甲、龙雕、云纹、层叠披风——立绘在游戏里的显示尺寸只有英雄卡的 208×286，这些细节全会糊成噪点，观感"脏"。要**大色块+最多 1~2 处金边**。
4. **暗沉配色 + 呆板正面站姿**：墨甲暗红土金没有主光，在游戏纸金黄 UI 里发闷；A 字正面握刀抚髯是"证件照"。

## 四、量产一致性三原则（120 将不画风漂移的关键）

1. **同一模板只换变量**：身份/称号/肤色表情/武器/主色/动作六个槽位之外，一个字不改。
2. **一次连生成**：同一批（比如整阵营 5 将）放在同一次会话里连着生成，风格最稳。
3. **生成后先缩略检验**：把成品缩到卡片尺寸（208×286）看一眼——剪影清楚、脸可辨即为合格；糊成一块的回去简化细节。

## 五、入包流程（已自动化管线）

文件命名为将 id（如 `guanyu.png`）→ 放 `assets/resources/art/heroes/` → 游戏自动显示（有图用图、无图回退占位）。
压缩流水线（600×800 + 256 色量化保透明，v1 的 1.2MB 源图 → 82KB）：

```bash
python3 -c "
from PIL import Image
im = Image.open('源图.png').convert('RGBA').resize((600,800), Image.LANCZOS)
im.quantize(colors=256, method=Image.FASTOCTREE).save('assets/resources/art/heroes/<id>.png', optimize=True)"
```
