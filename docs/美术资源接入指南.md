## 一、一页速览

**现在游戏长什么样？**
当前已接入120张武将立绘（16 SSR、24 SR、43 R、37 N），以及既有背景/UI皮肤、主城/战役/招贤殿/战场场景图和界面图标。立绘按需从微信 art-heroes 分包加载；空缺资源仍保留代码占位回退。

**图放哪里？**

| 类型 | 目录 | 文件名 |
| --- | --- | --- |
| 武将立绘 | `assets/art-heroes/`（微信分包） | `<将id>.png`，如 `liubei.png` |
| 界面图标 | `assets/resources/art/icons/` | `<图标key>.png`，如 `gem.png` |

**怎么生效？**
把 PNG 丢进对应目录 → 终端跑 `./scripts/cocos-build.sh web-mobile` → 浏览器打开 `build/web-mobile/index.html` 看效果。**文件名对上就自动显示，不用改任何代码**；没交付的位置继续显示占位，完全不影响游戏运行。可以一次交几张，逐步补齐。

**命名铁律**
- 只用**小写英文字母**（图标 key 可加下划线 `_` 和数字），**禁止中文、空格、大写字母**。
- 人物/图标收 **PNG**（图标透明底）；不透明场景可用 **JPG**。
- 文件名（不含 `.png`）就是资源 key，**一个字母之差就会一直显示占位**。武将 id 请从本文清单里复制粘贴，不要手打。

## 四、**包体红线（必读，超了就发不出去）**

> **包体方案（2026-10-02 已落地分包）**：微信小游戏主包硬上限 4MB、主包+分包总上限 30MB。武将立绘走 **`assets/art-heroes/` 微信分包**（构建自动生成 `subpackages/art-heroes/`，不占主包 4MB，30MB 上限内 120 张全量装得下）；界面图标走主包 `resources/art/icons/`（每枚 ≤5KB，总量 ~200KB）。**立绘交付仍须逐张压缩**（目标 ≤40KB/张），控制分包体积与加载速度。主包当前 3496KB、关羽分包 104KB 实测。

**体积要求**

| 资源 | 单张上限 | 压缩工具 |
| --- | --- | --- |
| 立绘（600×800） | **≤25KB** | tinypng.com 或 squoosh.app（选 PNG → 压缩后再下载） |
| 图标（96×96） | **≤5KB** | 同上 |

**预算怎么算**（为什么必须压缩）：
- P0 批次：16 张 SSR 立绘 + 6 枚货币图标——立绘进分包（每张 ≤40KB）、图标进主包（每枚 ≤5KB），无主包爆线风险；但**压缩仍是硬要求**（控制分包体积与首次加载）。
- 全量 120 张立绘若都按 25KB，约 3MB，**主包绝对装不下**。R/N 的 80 张必须在 ~15KB/张以内控制，或等二期方案。

**当前加载边界**：微信 art-heroes 分包已支持，远程 CDN 未接入。启动时只预载场景，头像/立绘在对应页面需要时按 `<将id>/spriteFrame` 加载；图鉴滚动时按视口加载。切页释放上一页已解码立绘，降低同时驻留的纹理数量。80 张 N/R 图片合计约 6.5 MB，文件压缩体积不代表纹理占用；低端微信设备的冷加载、峰值纹理与滑动流畅度仍需真机验收。

**自查方法**（macOS）：右键文件 →「显示简介」看大小；或终端 `ls -l 文件.png` 看字节数（25KB ≈ 25600 字节）。压缩后再放进目录。

## 五、交付与自验流程

1. **放文件**：把压缩后的 PNG 放进对应目录
   - 立绘 → `assets/art-heroes/`（分包），文件名 = 将 id，如 `guanyu.png`
   - 图标 → `assets/resources/art/icons/`，文件名 = 图标 key，如 `gem.png`
2. **构建**：终端进入仓库根目录，执行 `./scripts/cocos-build.sh web-mobile`
3. **查看**：浏览器打开 `build/web-mobile/index.html`，到对应页面确认：
   - 交了的图 → 原来印章/色块的位置换成你的图（立绘按框裁切，四边会有裁切属正常）
   - 没交的槽位 → 继续显示占位，不影响任何功能
4. **不对就查文件名**：图没显示，99% 是文件名拼错（大小写、多空格、中文输入法符号）。对照本文清单复制粘贴。
5. 不想自己跑构建的话，**把文件交给 AI 代理代跑构建与验收**也可以，说明「美术资源已放入，请构建预览」即可。

> 注意：游戏数据的真实进度在微信开发者工具/真机缓存里，Web 预览与正式包互不影响；`build/` 目录是生成物，不要手改里面的任何文件。
