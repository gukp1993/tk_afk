# V2 核心功能开发记录

日期：2026-09-27。范围：按既有 V2 优化顺序补齐核心循环功能；双平台共享 `src/` 与 `utils/`，不增加运行依赖。

## 已实现

- **操作与消费保护：**页面切换会使旧触摸作废；招募、集市兑换、付费快速收获均先显示项目、消耗和余额变化，再由独立确认提交。招募揭示期间可以立即揭示，完成后明确选择完成或查看新武将。召唤、快速收获、集市兑换写档失败时回滚资源与奖励。
- **主线目标：**点击当前军旗可查看敌阵、首通固定奖励、军械随机掉落概率、里程碑军械箱和预计挂机铜钱速率变化，并从详情直接自动出征。地图保留已通关、当前、未开放状态。
- **跨页自动出征：**战斗场景作为全局唯一会话持有者；切英雄、背包、玩法等页面时仍只更新一次战斗，战役底栏显示进行中/已结束状态并可返回原战斗。系统切后台会暂停，回前台可从战役页继续。启动另一场战斗前须显式结束旧会话；不能保存时不并行启动。
- **停止与回流反馈：**自动会话摘要显示起止关卡、胜负场数、耗时、实际战斗资源、经验/等级变化和挂机铜钱速率变化。自然卡关可直达当前成长目标；普通败北页也可查看成长入口。
- **招募与成长反馈：**重复卡显示星级前后变化及武将属性战力差；若该武将在出战队伍中则标明出战战力变化。新武将可以从结果页直达详情。既有统一等级、共享军械和自动升星规则保留。
- **挂机与奖励预期：**挂机弹窗显示真实每小时铜钱、招募令、精铁速率与12小时储存上限；付费快速收获展示费用、扣后元宝、时长与预计资源。当前关预览复用结算公式，固定奖励与随机军械分开说明。

## 验收边界

此提交完成 V2 核心功能代码开发，不代表发布验收。微信/抖音开发者工具与真机仍需验证长离线、杀进程重启、页面快速往返、窄屏自动战斗布局和弱网存档恢复。进程重启时现有存档规范会清理未结算战斗并标记中断，不补发战斗奖励；这是保持结算唯一性的恢复方式。
