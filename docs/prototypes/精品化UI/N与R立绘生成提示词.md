# N 与 R 立绘生成提示词

用途：补齐《挂机定三国》图鉴中的 N/R 品质武将。所有角色为原创三国题材 Q 版 3D 角色，不临摹任何现成游戏角色或美术资产。每名武将分别单独生成一张图，不生成拼图、文字、徽标、卡框或背景。

## 共用风格提示

透明背景，全身竖版 3:4 角色立绘，600×800 画布构图，角色居中，四周预留约 8% 安全空间。高完成度可爱 3D CGI Q 版三国武将，头身比例约 1:2.5，面部清楚，衣料有柔和织物褶皱与细腻材质，金属件有适度柔光高光，柔和棚拍式三点布光，轮廓边缘干净，柔和环境遮蔽，温暖国风配色，质感与既有 SSR/SR 立绘一致。武器和身体完整入画，不触边。无文字、无水印、无底座、无地面投影、无背景物件。

## 品质差异

- N：朴素布衣、简洁轻甲、素雅低饱和配色，小型或简洁配件，精神友善、读图清晰。
- R：更鲜明的阵营色、精致一些的衣甲层次、独特发饰或武器轮廓，但仍保持亲和的 Q 版剪影，不做 SSR 式夸张华丽光效。

## 角色个性补充

共用提示后，为每张图额外增加该角色姓名、性别与年龄气质、年龄气质、阵营、服装主色、标志性武器/配件和动作姿势。历史男性武将须保持男性面部与体态特征；女性角色按既定角色身份设计。不可将多个角色复用同一张立绘。
