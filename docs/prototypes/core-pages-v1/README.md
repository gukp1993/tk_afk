## 共用视觉规格

- 背景为单独的 1024×1536 原创无字绘画，不烘焙按钮、数值或中文。背景由内置 ImageGen 生成，具体提示词和边界在 [art-prompts.md](art-prompts.md)。正式开发时文字、数值、可点击区域、选中态需用 Cocos 节点绘制。
- 主色 `#102824`、深墨 `#0B201C`、铜金 `#D3AC64`、亮金 `#EFD69B`、绢纸 `#F4E9C9`、朱砂 `#983E31`。信息板使用深绿半透明材质，保证山水细节可见而文字仍清楚。
- 顶栏保留主公/战力、铜钱、元宝；底部五栏保留主城、玩法、战役、英雄、背包。底栏图标直接复用群英录已有原图集，未另造近似图标。原型画面边缘无手机胶囊遮挡；实际 Cocos 页面需适配安全区。
- 建筑、关卡与模式卡的视觉范围同时是点击热区。静态场景可铺满屏幕，但功能文字必须始终独立于背景，加载失败时入口也应可辨认。

## 页面层级与交互约定

| 页面 | 首屏层级 | 对应现有 Cocos 入口 |
| --- | --- | --- |
| 主城 | 主公资源 → 城市地标（点将台、群英殿、演武场、铁匠铺、集市、军机营）→ 当前章节/关卡 → 挂机收益 → 自动出征/练兵 | `CampaignScreens.home`；建筑映射沿用 `CITY_BUILDINGS`。 |
| 玩法 | 主公资源 → 王庭诸事标题 → 群英塔/演武场/军械图鉴/集市 → 每日任务等快捷入口 | `CampaignScreens.journey`；四张模式卡保持现有路由。 |
| 战役 | 主公资源 → 当前章节进度 → 已通关/当前/未解锁关卡路线 → 5人阵容 → 挂机宝箱 → 自动出征 | `CampaignScreens.campaign`、`stagePreview`；数值继续读取规则源。 |

原型中的 **Lv.40、12.8万、1888、18层、3/10关、五人阵容与收益**均为设计演示，不能写死到游戏存档。页面开发时读取当前玩家等级、资源、编队、关卡、闲置收益、塔层、演武次数和军械解锁数；不改变现有规则。关卡弹层需呈现敌阵和首通奖励，锁定关卡不启动战斗。资源领取与自动出征在原型中仅弹说明，不调用真实逻辑。

## 审查边界

三张背景和 HTML 原型已在浏览器 390×844 视口实看；关卡点击可显示说明弹层，其他入口均有预期去向。未改 `assets/scripts/`、规则、存档或 Cocos 场景；未进行微信开发者工具/真机性能验收。后续依 `AGENTS.md` 的 Cocos CLI 约定在根目录工程开发，避免把整屏原型图当成可交互游戏页面。
