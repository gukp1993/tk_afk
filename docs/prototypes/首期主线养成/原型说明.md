# 首期主线养成交互原型

[打开原型文件](index.html)。单文件 HTML，不依赖第三方图片、字体或运行包；建议在桌面浏览器查看完整 390×844 手机框，或直接在手机尺寸视口查看。

若本地 Markdown 文件查看器只显示 HTML 源码，可在仓库根目录运行：

```bash
python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/prototypes/首期主线养成
```

随后在浏览器打开 `http://127.0.0.1:8768/`；看完在终端按 Ctrl-C 停止服务。此预览不用 Cocos CLI，不会启动游戏构建。

| 页面 | 对应需求 | 可点击路径 |
| --- | --- | --- |
| 战役 | R01、R03～R05 | 选择第 40、90、100、110、120 关 → 首通预览 → 模拟胜利。 |
| 日常 | R02 | 模拟胜利到 3 场 → 挂机领取 → 返回日常 → 领取全部。 |
| 首通结算 | R03～R05 | 显示基础与章节奖励、独立里程碑奖励；可返回战役。 |
| 挂机与广告 | R08～R10 | 先试提前关闭，再完整播放 3 秒并领取；核对余额与剩余次数。 |

原型只演示信息结构与触摸流程，初始值是虚构演示存档；点击“模拟胜利”不运行战斗，点击“领取”不修改玩家存档。最终奖励规则以[执行方案](../../plans/首期三十天主线养成与奖励.md)和[经济方案](../../plans/wechat-economy.md)为准；美术细节及 Cocos 节点布局由实施任务落实。
