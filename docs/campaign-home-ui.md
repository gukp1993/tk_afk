# 三国战役首页 · 占位版

本轮依据用户提供的 IMG_7747.PNG 的信息层级设计：顶部账号和资源，中间纵向征途，侧边快捷入口，下方队伍、挂机宝箱与主行动，底部战役居中。山河、城关、军旗、武将与宝箱均为程序绘制的原创占位，没有导入参考游戏的图片或文案。

## 页面与交互

- 游戏默认进入战役；底栏为主城 / 玩法 / 战役 / 英雄 / 背包。建筑主城继续保留，召唤由战役右侧或主城点将台进入。
- 地图显示当前章节，每五关一段；军旗对应真实关卡，朱砂旗表示当前关、青绿旗表示通关、灰绿旗表示未开放。点击旗帜查看状态；左下“征途”查看本章十关。
- 右侧任务、召唤、背包、军械均接入已有页面。下方出战武将取当前编队，点击调整编队。
- 自动出征沿用现有自动战役与有限练兵规则；练兵沿用原有自动练兵。挂机宝箱与“一键收获”复用聚合领取，近期目标复用进度引导。
- 顶部等级、经验、战力、资源，地图进度和下方挂机累计均取存档；本轮不改玩法数值、存档结构或发奖规则。

## 后续换美术

`src/campaign-art.js` 独立绘制地图、旗帜、营地和宝箱；`src/screens/campaign.js` 管理布局和 IMGUI 命中。替换占位时保留归一化路径 ROUTE 与旗帜脚点坐标，队伍区域右侧预留挂机宝箱。逻辑画布宽 375，竖屏首页按高度布局。

顶部采用墨绿、铜金；地图为青绿山河与浅赭古道；当前军旗为朱砂，出征按钮为玉绿。正式立绘、图标和场景细节可后续替换。

## 本地体验与验证

`node preview/mini/play.js` 生成内存档交互预览；默认战役，`?height=568` 检查短屏，`?height=667` 检查中屏，`?demo=1` 展示第20关，`?page=map` / `quests` / `idle` 展示对应弹窗。预览不访问设备存档。

`test/campaign-navigation.js` 覆盖三种高度的入口、导航返回、弹窗隔离、领奖幂等、自动出征中断返回，以及章节边界与循环章节。现有主城和全局导航回归一并保留。验证明细见 session_context.md 本轮交接；小游戏工具和真机验收仍需单独进行。
