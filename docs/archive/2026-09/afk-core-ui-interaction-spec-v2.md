# 主线、召唤、挂机：剑与远征实测与三国适配规格 v2

日期：2026-09-27；依据：iPhone镜像实际操作、客户端内置说明，以及本项目当前源码只读核对。前轮记录见 `afk-arena-pve-field-notes-v1.md`。本轮交付研究与执行规格，没有修改游戏运行代码，没有验证本项目真机品质。

目标是接近原作基础循环的操作感、信息层级和反馈密度。美术、角色、技能、文案继续采用原创三国内容。本规格不推翻统一等级、共享军械、重复卡自动升星与低负担定位；原作的数值和账号状态不是本项目默认配置。

### 2.2 自动推图与普通战斗是两层能力

- 普通战斗里的“自动”是自动释放必杀；备战页的“自动战斗”则启动连续挑战。两个概念应有不同文案，不能只放一个模糊开关。
- 自动战斗启动提示使用当前阵容连续进行。首次教学明确支持切到其他页面且不中断。
- 实测切到英雄页时，底部战役图标变为交叉武器，并显示当前关号；先后观察22-13、22-15。返回战役时显示自动战斗中、当前22-16、推进4关。不是仅看教程推断跨页能力。
- 自动页保留底栏；普通单场页底部主要是五名英雄和技能操作。自动页重点转为推进状态和停止控制，降低主动操作负担。
- 自动胜利能继续下一关，不需要每局手点奖励。点击暂停位置后出现退出面板，显示推进5关、当前22-17、挑战时间1分24秒和若干每分钟收益展示。此处数值**不能直接当挂机速率提升量**；未核实统计公式。
- 点退出后结束自动，最终回到当前关卡备战；退出过程中曾短暂出现首页，说明截图可能处于过渡帧。再点备战返回，才稳定停留战役首页。不能按过渡帧连续点击重要操作。
- 前轮普通战斗已验证暂停菜单有退出、再次挑战、继续，胜利有下一关、奖励和任务进度，失败有成长指引；自动失败处理仍待实测。

### 2.4 召唤：先有结果，再组织揭示与培养入口

- 主城建筑进入酒馆，顶层还分酒馆/占星屋/时光殿堂；本账号首次落在时光殿堂，手动切普通酒馆。必须显示当前卡池名称和实际支付资源，不能靠背景判断卡池。
- 全英雄池显示单抽300、十连2700；概率说明：普通51.69%、稀有43.60%、精英4.61%、SP 0.10%，不包含部分种族。均为当前原作公示，不能替换项目四档固定概率。
- 宣传文字保证十连含稀有或精英，不等于“十连必出最高档”。本轮不对隐藏保底作判断。
- 心愿单按阵营分组，说明提高精英出现时命中心愿英雄的机会，不提高精英总概率；本轮只查看，未改用户心愿单。
- 召唤开始即扣费，之后是十张背面卡。可点单张翻开，边框/光效表达品质，快速翻牌能加速。出现新英雄时进入完整角色展示，展示技能和类别，点击技能出现说明并观察到角色动作；返回继续结果。

- 退出后弹出酒馆附奖和普通英雄自动分解所得。累计条从初始20/30变为最后10/20；不能据此还原全部档位奖励表。
- 新英雄、重复卡、低品质处理属于不同结果类型，项目必须用自己的规则明确展示：新武将入册、重复自动升星、满星溢出留存。

### 2.5 英雄、装备、编队与共鸣

- 英雄列表采用5列密集卡片；单卡同时表现阵营、等级、品质框、星、红点。顶部有容量与排序，底部有阵营筛选及编队/热度/英雄/图鉴子页。排序菜单可选战力、品阶及后期系统指标。
- 单英雄详情以角色为中心，装备位置分两侧，品质星级在上；下方战力、生命/攻击/防御、升级主按钮；一键穿装是次操作。技能用独立子页，同一角色展示与属性位置保持稳定。
- 当前220级主力升级被阻挡，按钮灰显，旁边准确说明需要所有水晶祭司达到200级。比只弹“不能升级”更可理解。
- 装备详情按名称/等级、属性、种族加成与操作区组织。强化页展示等级与属性、材料网格、一键填充、金币用量、确认按钮。本轮查看满强化装备，未验证实际强化增长。
- 技能页显示技能等级、当前效果和已解锁等级差异；点击技能能看到对应动作。项目无需照抄复杂技能文本，宜用一句职责+当前效果+下一成长节点。
- 编队收藏页显示一个已有队伍、添加入口和长按编辑提示；没有保存/覆盖。主线实测支持站位拖动，不等于收藏编队功能已完整验证。
- 共鸣页面上方是5名最高等级英雄，下方共享槽位。本账号上方220/220/220/180/180，下方180级。内置说明：槽位英雄随五人最低等级，受品质上限限制；移除产生24小时槽位冷却；五人240后规则变化。均未实际移除或突破。
- 进阶入口先选英雄、再展示材料槽与受保护/不可用卡片，提供升星与一键进化。本轮只到材料预览。项目已选择重复卡自动升星，不重建吃卡系统。

### 2.6 任务与背包连接核心循环

- 日常页顶部剩余刷新时间、20/40/60/80/100进度宝箱，任务行显示积分、进度及领取/前往。已完成挑战首领、召唤、爬塔的任务可领；未完成升级/强化有前往入口。本次未看到一键领取，不能推断全游戏没有。
- 主线页按具体里程碑列出奖励和进度。例如22-12完成可领250钻石，22-30仍未完成。均只查看，未领取。
- 背包分道具、装备、藏品、全部；点击物品先看描述和用途再使用。项目可保留更少分类，以当前实际资产为准。

## 4. 可交给其他 harness 的实施批次

以下是建议规格，未在本轮实施。依序交付，每批检查现有实现，不叠加同功能的新系统。触及数值、站位和存档的独立变更需明确列出迁移及验收，不能夹在UI改造中。

### A：先完成核心交互与消费保护

1. 明确页面状态：正常、加载、空、可领取、已领取、资源不足、失败。所有主按钮有唯一动作，付费按钮始终可见价格与资源图标。
2. 消费操作先显示“项目/数量/费用/扣后余额”确认；持有招募令与元宝的入口不静默替代。只在确认后提交一次事务。
3. 翻牌/跳过/关闭永远不能在同一手势生命周期内变成消费。揭示区与再次招募分开；动画结束前不注册付费命中区；新一次消费必须重新确认。
4. 触摸按下绑定控件ID与页面版本，抬起必须仍属于同一控件/版本；弹层变化清除旧触摸。按钮消失、场景切换后，旧坐标和旧回调失效。
5. 结果在开始展示前完成扣费、发卡、持久化；动画只读取结果。关闭、跳过、切后台、反复打开不重新抽取或发奖。存储失败显示准确状态，不能双扣后再用动画掩盖。
6. 统一遮罩点击为关闭/无操作，禁止领取或消费。奖励领取必须明确动作；不复制原作空白领取行为。

验收：快速连点付费按钮、按下后弹层切换、揭示结束同帧点击、取消确认、余额不足、切后台、保存失败重试；均不额外扣费/发奖。UI低成本改动无需机械补测，但消费与生命周期必须有真实状态断言。

### B：主线首页与备战先形成完整目标

- 保留现有原创地图首页，信息顺序固定为：当前章节/关卡 → 下一可获奖励或解锁 → 出战队伍/挂机 → 自动出征。常用入口不被活动红点挤压。
- 点击当前关卡可看敌队、角色职责、首通奖励、是否首领、推荐编队；普通关可直接出征，首领详情不强制阻塞自动会话。
- 章节页展示已过/当前/未解锁状态、明确解锁条件、真实下一阶段产出差值。不依据章节插画或故事推测数值。
- 编队保留点击换将；若增加拖动交换，必须支持拖回原位、拖到空位、越界取消，交换后立即重算展示。推荐阵容仅基于拥有的英雄，不强制读攻略。
- 原作2前3后与项目3前2后是战斗规则差异。本批沿用现有配置，另列平衡改版；不能只移动画面、内核仍按旧排判断。

验收：小屏下不遮挡出征/返回；敌阵与实际开战一致；未解锁节点不能开战；首通奖励文案与结算一致；新英雄可从结果到详情再到编队，返回路径不丢状态。

### C：跨页面自动出征作为独立架构改造

这是最接近本次原作体验的新增能力，替代旧v1“离开战斗页就停”的边界；必须单独实施、验收，不能把现有版本描述成已经支持。

- 全局唯一前台会话持有战斗引擎、状态机、battleId和结算；战斗场景只负责展示与输入。页面切换仅解除视图绑定，不销毁会话；`app.frame`每帧只更新一次会话。
- 底栏战役入口在运行中显示交战标识、当前关、推进数，点击回到同一个实例。进入英雄/召唤/背包时继续，开模态窗口不自动暂停游戏内战斗。
- 区分**应用内切页**与**应用切到系统后台**：跨页继续；系统onHide暂停并保存，onShow显示可继续。首版仍不离线推关，不声称后台挂机等于关闭游戏继续通关。
- 保留现有有限练兵恢复和本场后停止；主动立即停止按已有中断规则处理。自然卡关最后停止后展示原因和一个可执行成长入口，不启动无限重试。
- 战斗开始固化阵容/数值快照；本局进行中培养或换阵对下一局生效，并明确提示。改变配置不能使半场数据混杂。
- 存在会话时发起塔/单场战斗，先选择结束当前会话或返回；不得并行创建第二战斗。实际停止成功后才能开始另一模式。
- 会话停止摘要：开始/结束关、推进数、胜/败/练兵场数、前台耗时、实际结算资源、等级变化、挂机速率前后差值。速率与本轮赚取分开，不使用不清楚的“收益+每分钟”统计。

验收：战斗/英雄/召唤/背包来回切20次；同一battleId仅结算一次；系统后台再回流；保存失败；快速停止再开始；切页期间获新英雄/升级；启动另一战斗；最终没有孤立引擎或持续扣费。现有onHide只通知顶层页面，必须把会话生命周期提升到全局才能通过。

### D：挂机让“等一会儿会得到什么”可预期

- 宝箱面板按累计时长/12小时上限、当前真实速率、累计掉落、领取四层显示。首次空态、少量收益、封顶状态分别给出准确说明。
- 领取后立即展示已到账明细和新的计时起点；返回再开仍为同一起点，不能因打开面板而清算或重置。
- 主线胜利达到实际产出变化节点时给简短“产出提升”提示；固定的招募令/精铁速率保持原值。下一档预告来自配置，不能硬编码“每关全部提高”。
- 快速收益单独展示费用、时长、预期资源、次数与重置；不与免费领取共用主按钮。沿用项目当前规则，不抄原作次数。
- 免费一键收获保留，明细区分挂机、任务、活跃宝箱；未领取自选类奖励保持待选择，不代选、不引导必看广告。
- 主公经验仍只由战斗结算；不因原作挂机有经验就悄悄增加新的英雄经验资产。

验收：同秒重复领取、1分钟/1小时/封顶、跨日、设备时间异常、返回再领、推图前后产出、聚合领取与单领交错；金额及时间守恒，旧档兼容。真机长离线另记，不把短后台观察当长离线测试。

### E：召唤结果直接连接“我的队伍更强了”

- 保留当前四档固定概率、无保底和2880元宝十连。卡池标题、概率、资源与价格固定展示；首版只做现有普通池，不新增付费池/心愿单系统。
- 结果有自动揭示和一键揭示；高品质/首次获得可短暂突出，允许立即跳过。新英雄卡可看职责、技能和推荐位置，不强制读长文或分享。
- 重复卡展示“原星级→新星级”和真实属性增量，满星显示留存卡数量。十连多张同名卡按真实事务顺序汇总，不能每张都显示相同的错误起点。
- 结束主按钮为完成；次操作为查看新英雄/编队。再次招募处于独立区域且再次确认费用；返回不会触发消费。
- 展示“全队提升”时仅用真实受影响的上阵队伍计算，不把收藏战力当出战提升，不自动换阵。

验收：全重复、全新、十连连续同名、同轮达到满星、无材料、短屏滚动、揭示期间退出/后台、重新打开结果；资产只变更一次，结果与仓库一致。

### F：成长页完成闭环，不增加养成负担

- 英雄列表突出已上阵、新获得、可处理溢出卡三种状态；筛选/排序状态返回后保留。红点只标明确可操作事项，查看说明不等于完成操作。
- 详情固定角色职责、等级/星、战力/主要属性、技能。等级用“跟随主公”等准确说明，去除无意义个人升级按钮。
- 共享军械页突出当前启用装备、替换前后全队变化、升阶需要和持有；一键启用只处理明确免费选择，不自动耗材。
- 卡关引导按真实可用资源给一个动作：可免费更换军械、可培养军械、可练兵、暂无可提升等。点击直达对应对象，而不是泛泛跳英雄列表。
- 任务未完成时给正确入口，完成后可单领/全领，奖励与下一目标联动；保留核心日常不强迫塔/抽卡的规则。

验收：抽到新将→查看技能→推荐编队→回到出征；卡关→成长入口→看见实际提升→重试；下线后回来→领取→处理成长→继续推图。各路径真机录像/操作记录包含实际耗时与卡点。

## 5. 实施顺序与交付要求

1. A消费与输入保护先验；B与D完善基础页面；E与F完善结果到成长链路。各批保持独立提交，不引入新运行时依赖。
2. C跨页会话是独立大改，先写生命周期/结算测试再迁移，保留既有有限练兵和存档兼容。它不是单纯“让底栏可点击”。
3. 调整`utils/`或`src/`按仓库规则跑smoke/static-check；渲染改动再做离屏审查与真实Canvas小屏交互检查，打包前build。微信与抖音生命周期分别真机验证。
4. 首发只在真实新号与回流体验完成后验收；当前高等级参考号连续赢5关不证明项目新手平衡。留存效果需要实际玩家数据，本文不承诺。
5. 本轮未深测时光之巅/奇境等全部旁支PVE，也未试礼包/充值/PVP。本轮核心交互深度高于前轮，不等于整个原作功能全集已调查完毕。
