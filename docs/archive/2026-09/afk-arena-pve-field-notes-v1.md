## 2. 直接观察到的机制

### 主线：战斗、收获、下一步紧密衔接

- 战前双方五人，**前排2人、后排3人**；显示敌我战力、英雄等级、阵营和出战勾选。主线22-11显示我方1495K、敌方1101K。战力展示不能据此推导胜率公式。
- 战前存在普通战斗、自动战斗、推荐阵容入口。本轮使用普通战斗，未实测连续自动战斗的停止条件、推荐阵容算法。
- 不点击英雄也会普通攻击；开启自动按钮时明确提示自动施放必杀技。角色有生命和能量反馈，击杀时可见能量增加提示。
- 战中有自动、2倍、4倍以及暂停。暂停后可以退出、再次挑战、继续；本轮实际使用暂停/继续和4倍速。
- 胜利页同时给奖励和任务进度，提供下一关与战斗统计入口。22-10和22-11单场均显示6700金币、4600经验及44K蓝色资源；未点击资源说明，不把蓝色资源名称当作已核实事实。
- 点击下一关进入下一关战前准备，原有阵容可直接再战；结算页空白处继续可返回主线。
- 战役首页同时可见当前关卡、路线、挂机队伍和宝箱。未领取挂机宝箱，未核实离线收益上限及准确公式。

### 爬塔：复用战斗，提供另一条推进目标

- 总入口包括普通塔与阵营塔；部分阵营塔标注按星期开放。
- 普通塔展示已过层、当前挑战层、下一层预览和敌阵；本次当前251层，250层标记已通关。
- 当前251层敌方1735K，我方1495K；失败后显示提升英雄等级、提升英雄品质、调整阵容与再次挑战入口。
- 本轮未验证塔首通奖励、全部阵营塔限制、每日次数等规则。不能把入口显示当作规则全集。

### 迷宫：短期强化与路线选择形成单独体验

- 当前页面显示共3层。内置规则明确：48小时刷新；只能探索相邻格；前进后同排其他格被摧毁；怪物、奖励、建筑刷新重生。
- 内置规则说明击败守卫获得专用货币，战胜怪物获得遗物选择；遗物只在迷宫内生效，刷新后消失。30-60解锁快速挑战是当前内置说明，不代表已在本账号实测。
- 实际路线可见普通/精英守卫、援军马车等节点。进入守卫前可预览敌队和奖励。
- 第一场胜利后实际出现三张遗物：补给强化、开战回能、条件减伤。点卡片查看效果，再点选择完成；选择后出现下一排可达路线。
- 这证明其差异不只是换一张战斗背景，而是“选路→战斗→获得本轮强化→再选路”。本轮未验证多场状态继承、复活消耗、失败回滚、第二/第三层和首领。

## 3. 对本项目的建议执行顺序

以下是基于实测的产品建议，不是新增功能已获验收的声明。现有统一等级、共享军械、重复卡自动升星继续有效；先核对最新实现，避免重做已有功能。

| 优先级 | 要交付的体验 | 交给执行者的验收点 |
| --- | --- | --- |
| P0 | 主线连续推进有明确收获 | 验现有自动出征：一键开局、胜利自动下一关、明确本轮过关/资源/升级累计；中断恢复不重复结算 |
| P0 | 卡关后有可执行的下一步 | 验现有有限练兵恢复；最终停止时只突出一个当前能做的成长行动，有材料就直达培养，暂不可成长则展示准确资源缺口和回流目标；不用一组泛泛提示替代 |
| P0 | 战斗能看懂谁在发挥作用 | 核对伤害、治疗、护盾、控制、阵亡和技能释放是否有清楚反馈；先保证事件准确、角色可辨识，不以堆特效替代；自动模式少弹窗 |
| P0 | 新手和回流真实可玩 | 实测新号首20关、首次卡关及一次离线回流，记录每个卡点的时长、资源与解法；当前老账号强压前两关不能证明新手节奏合理 |
| P1 | 塔作为主线之外的可选目标 | 改进已有塔的当前层、下一档奖励和一键挑战；检查是否真正补充培养资源，核心日常不强制打塔；暂不扩展阵营塔 |
| P2 | 迷宫提供偶尔换口味的玩法 | 首发核心循环验收后再单独立项。低负担版本先考虑短路线、清楚的少量强化、推荐选择；状态继承/复活/刷新/奖励去重必须另写完整规格后实施 |

最先要学的是**玩家少操作，仍持续看见自己推进和变强**。不要因为原作拥有很多模式，就把全部系统一起移植。迷宫的选择负担明显高于主线，适合作为可选内容。

## 4. 后续需要补证据的部分

完整复刻规格仍缺：自动连战停止/重试边界、挂机收益与关卡提升关系、连续迷宫状态继承及失败行为、三层流程、时光之巅与奇境探险实际流程。后两者本轮只见入口，不能宣称已体验。

本项目历史方案为3前2后，原作实测为2前3后；是否调整属于独立设计决定，要核对现有战斗实现并验证坦克/治疗覆盖，不能作为本次调研的顺手改动。全部武将、技能、文案和资源仍采用原创三国内容。
