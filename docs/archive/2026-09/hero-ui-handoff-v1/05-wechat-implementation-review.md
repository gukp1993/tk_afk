群英录使用三列立绘卡、阵营徽章、品质框、姓名/星级、出战标记、阵营筛选和排序。已拥有武将按实际存档显示；当持有数量不足九名时，后面的预览卡明确标记“未获得”，点击前往点将台。页面顶部的持有数量和主公共享等级读取游戏状态，不使用原型图中的演示数字。首胜升星入口放在标题区，以减少卡片上方的空白。

关羽详情使用现有透明立绘和城关背景，显示共享等级、上阵状态、属性、技能、全军军械和编队入口。技能与属性可以点击查看说明；下方成长和卡券内容可滚动浏览。关羽以外九名武将新增独立透明立绘，运行资源使用 1024×1536 RGBA 高清图；立绘生成记录及后续同风格提示词见 [portrait-prompts-a.md](portrait-prompts-a.md) 与 [portrait-prompts-b.md](portrait-prompts-b.md)。

本轮还修正了图集裁切的纵坐标，避免 N 品质卡框、阵营章和技能图标串图。已验证 TypeScript 类型检查、规则镜像检查、Web Mobile 与微信小游戏构建；在 Web Mobile 预览中实点了英雄卡、技能说明、返回、阵营筛选和未获得卡跳转。微信开发者工具与真机触摸、加载和性能仍需设备验收。抖音端不在本轮验收范围。CDN 接入留给后续阶段。
