# 主城与功能导航（已实施，待用户验收）

日期：2026-09-26。此文档描述本轮运行代码，不替代英雄、装备或战役地图的独立方案。

## 页面结构

- 首次进入：主城。顶部是游戏名、战力、铜钱/元宝/招募令；中央主线卡片点击出征。
- 三个常用入口：召唤（获得新武将）、英雄（查看与培养）、背包（资源与装备）。首页与底部入口进入同一个页面。
- 挂机收益：直接领取；加速/双倍收进独立弹窗，保留原有业务。
- 次级入口：编队、每日任务、集市、更多玩法；下方是出战阵容。
- 底部固定五栏：主城、英雄、召唤、背包、玩法。功能详情保留返回按钮，返回原先的一级页面。
- 背包新增资源/装备两类；显示真实存档数量、用途、闲置/穿戴数量。点击资源跳转使用场景，装备穿戴强化进入现有铁匠铺。
- 英雄页筛选、排序分行，头像与文字分开；召唤十连结果支持滚动，确认按钮固定可见。
