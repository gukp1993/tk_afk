# 轻负担挂机体验打磨 v1 · 实施与验证记录

日期：2026-09-26。对应规格：`docs/idle-game-polish-v1.md`。状态：**已实施待验收**。

## 已实施

- A：接入纯状态机与真实战斗场景；战役连胜自动推进、失败后最多两轮有限练兵、独立练兵有限批次、4倍速默认并记忆选择；自动战斗不自动打开剧情，手动打开剧情会暂停。后台暂停需玩家继续；切页/返回会停止会话并中断未结算战斗。开局、结算、中断走同一存档入口，失败后不会开下一场，提供重试保存。
- B：每日活跃改为挂机领取30、任意1胜30、任意3胜40；原任务ID和单项奖励保留，其余任务可选。新的一键收获将挂机资源、已完成日常与新达标宝箱按一个事务领取；空挂机收益不计任务。主城显示一张由真实存档派生的近期目标卡。
- C：一键布阵改为可预览后一次原子应用的均衡推荐；不自动换阵。库存SR/SSR券可从集市直接使用；目标路由定位首胜、自选券、升星与军械箱。军械页提供已解锁N/R/SR免费启用建议；不动已启用SSR、不自动解锁或升星。英雄升星/军械操作展示真实战力或全军属性反馈。
- 存档未升版本；自动倍速是可缺省设置，不会在加载时自动开战。聚合领取、首胜选择、库存自选券、英雄升星、批量布阵及军械操作成功后立即保存。
