# 建筑式主城 · 占位 UI

2026-09-26，已实施，待用户体验验收。

## 页面布局

参考《剑与远征》的城镇入口组织方式，采用原创三国建筑轮廓和浅色场景占位，不使用其美术素材。

- 顶部：主公、战力、铜钱、元宝、招募令；内核提供玩家等级时显示等级与经验。
- 中央：可点击的点将台（召唤）、群英殿（英雄）、演武场、铁匠铺、集市、军机营（编队）。
- 两侧：每日任务、背包固定快捷入口。真实可领任务才显示提示。
- 下方：当前章节、出征、挂机领取、加速/双倍；内核具备统一等级与结算接口时保留练兵按钮。
- 底栏：保留主城、英雄、召唤、背包、玩法。群英塔仍从玩法进入。
- 短屏：城镇单独上下滑动，资源、快捷入口、出征/挂机和底栏固定。

## 替换正式美术

`src/city-art.js` 只负责地面与建筑形状；`src/screens/city.js` 的 BUILDINGS 定义入口名称、坐标与跳转。替换建筑绘制即可保留原命中与功能逻辑。当前使用低成本几何占位，无图片下载、运行时依赖或新增构建链。

首页注册名仍是 home，指向 city.js；city 复用 home.js 的任务、挂机与生命周期方法。当前另一会话正在修改 home.js 的玩家等级业务，为避免覆盖，其旧 draw 保留但不被注册调用。后续调整首页可见布局应改 city.js；任务/挂机业务仍由 home.js 维护，勿误将注册指回旧信息面板。
