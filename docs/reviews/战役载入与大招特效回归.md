# 战役载入与大招特效回归

时间：2026-10-05；状态：已实施待微信设备验收。主agent收口，battle_art实施BattleFx，interaction_audit与visual_audit分别独立核验载入和战斗。范围来自用户的旧背景闪换反馈及简单战斗/大招动画要求。

## 已实施体验

首屏先显示专用载入页，场景和基础图标就绪后进入当前选定页面，武将继续后台加载。8秒后允许手动进入；失败/跳过使用统一深绿地图底，恢复时淡入0.2秒，路线/关卡坐标不跳变。切页或销毁后迟到回调不会重画战役。

战斗新增近战刀弧、远程箭矢、法术符文与粒子，未知职业用金色冲击环。大招三段共0.8秒，普通攻击0.34秒；按战斗加速推进。大招数字与抖动排到0.48秒命中段，中央技能横幅最多一条。最多4大招/8普攻光效、每序列11节点、24项待播数字；群体光效最多3真实受体，真实群体数字完整显示。Graphics只在创建时绘制，无新增纹理与第三方依赖。

## 验收边界

规则血量仍即时结算，动画不延迟真实战斗。死亡/复活立即清关联待播数字；致死大招末次飘字可能被清除，结算不会等待完整末击演出。本批实际验证真实致死队列清零，不声称结算后仍完整播放大招。

微信设备的分包冷启动、纹理内存、触摸手感和持续战斗性能尚待验收。此次Web帧率来自隔离测试场景，不代表手机帧率。后续UI仍需打磨编队/任务/演武及剩余R/N美术，不能称全游戏美术已完成。
