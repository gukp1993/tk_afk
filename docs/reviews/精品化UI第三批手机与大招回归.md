# 精品化 UI 第三批：手机适配与 SSR 大招回归

- 日期：2026-10-05
- 状态：已实施待微信真机验收
- 范围：关卡预览与演武卡片、微信安全区换算、次级页面背景、16名SSR全屏必杀场景。

## 已完成

- 顶部/底部安全区从微信 `safeArea` 换算为720设计坐标，作用于标题栏与底部导航；返回/关闭热区扩大。`utils/platform.js` 对缺少信息和平台异常均回退为0。
- 关卡预览加入真实敌将立绘，敌卡副说明改为单行等级，战术效果缩为单行短标签，并在窄屏局部放大正文。
- 演武对手展示五人队伍，首位主将头像放大，其余队友收为阵容带。
- 新增演武场与名人堂系背景；演武排行、群英塔、剧情回顾、图鉴和成就复用殿堂背景。
- 16名 SSR 各自拥有一套程序化全屏主题符纹。场景层在背景之后、单位/HUD之前，长屏纵向缩放；结果页等待活跃与队列播完，规则结算保持即时。战斗页重绘（如切换倍速）会在正确层级恢复尚未播放完的场景。

## 验证

- Creator Web 构建成功；Playwright 在 360×740、390×844、430×932 下进入战役、演武和关卡预览，九个页面状态均可打开、没有页面异常。关卡预览第五张敌卡说明单行留在卡片内；三种屏幕均未见敌卡/演武对手队伍越界。
- 同一会话真实进入首战并观察到 SSR 全屏演出；演出期间点击加速后仍在战场层正确显示，最终抵达结果页，`__tkDiag().fx` 与 `ultimateScenes` 均为0。抽测的是正常战斗与重绘路径，不代表逐一实测16种主题。
- `node scripts/cocos-sync-domain.js --check`、Creator TypeScript `tsc --noEmit --pretty false` 通过。
- `./scripts/cocos-build.sh wechatgame` 在最终代码后构建成功。包体按当前生成目录统计，主包3,749,864字节（约3.58 MiB），低于4 MiB；艺术资源位于独立 `art-heroes` 分包。
- `node test/smoke.js` 在本轮早些时候通过622项；随后重跑被并行修改的 `utils/story.js` 阻断：该 JavaScript 文件在第540行包含 TypeScript 类型标注。该变更不属于本轮 UI 范围，未纳入本批提交。纯界面修改没有数值变更，本批按 `docs/reviews/回归基线.md` 规则跳过200种子仿真。
