## 二、缺陷登记（只登记不修）

### D1（P2 · 实现级）新 SSR「初登场」高光浮层被 SSR 信息栏完全遮盖 —— R3 复验不通过

- **实拍**：预置存档（保底计数拨至临界）构造「十连含新 SSR」（貂蝉），揭示期连拍 16 帧 + 完成全景，无一帧出现 DebutCard；信息栏始终以常态显示（`/tmp/tk_round2/sup/i5v3_rev00..15.png`、`i5v3_final.png`、`i5v3_grid.png`）。
- **代码定位**：`assets/scripts/screens/HeroScreens.ts` 581-593 DebutCard（y=-290，高 84，即 UI 带 -332..-248）在 581 行块先绘制；596-602 的 DrawGap 信息栏（y=-300，高 140，UI 带 -370..-230）**后绘制且纵向区间完全覆盖 DebutCard**——Cocos 同层后绘者在上，浮层被压在信息栏正下方不可见。与 R5（SummonSoft 被 SummonPool 盖住）同类 z-order 缺陷，即 R3 收官记录里「高光浮层压信息栏 4s 淡出」方案的实现未达成"压"的效果。
- **旁证**：DebutCard 的 3.6s+0.4s 淡出自毁 Tween 若在跑，对画面无任何可见影响（被遮挡），玩家永远看不到「初登场」引言。
- **建议修法（供排期参考）**：DebutCard 绘制块移到 DrawGap 之后（后绘即在上），或复用 R5 的重排思路给浮层让位。

### D2（P3 · 观感/语义）结果页信息栏「SSR 收集 0/16」为满星口径，与新 SSR 同屏并存易误读

- **实拍**：十连抽出 NEW 貂蝉（SSR 卡在网格首位），信息栏仍显示「SSR 收集 0/16 · 缺口：貂蝉·★0 …」(`i5v3_rev03.png`、`i5v3_final.png`)。
- **代码口径**：`utils/store.js` 1780-1797 `summonGapInfo` 的 `ownedFull` 只计**满星** SSR，缺口列表含「已有未满星」（★0 排前）。数据无错，但「收集 0/16」与同屏新 SSR 卡并存，玩家直观感受为矛盾。建议文案区分「满星收集 x/16」与「已获得」，随真机验收顺带评估。

### D3（P3 · 观感贴边）集市自选券浮层滚动区底缘与「暂不选择」按钮相切

- **实拍**：`/tmp/tk_round2/sup/shopv3_srPick.png`（SR）/`shopv3_ssrPick.png`（SSR）：第 5 行武将卡被固定「暂不选择」按钮上缘裁切，卡面在按钮后可见断边。浮层可滚动补偿、无功能阻挡，属贴边类，随真机验收顺带。

### D4（P2 · 实现级）资源 pill 落地脉冲只播一帧且尺度永不复位（I3 交互线）

- **实拍**：campaign 挂机 45s 后一键收获，顶栏裁剪连拍（帧距约 33ms，帧偏移 +390~+850ms，罩住 +500~700ms 预期脉冲窗口）：飞包「钱/宝」印章在 +420ms 帧清晰可见飞行中（`i3v3_strip.png` 第 3 行）；印章到达后 pill 宽度从 170px 变为 182px 并**恒定保持到连拍结束**（+450~+850ms 全部 182，像素测量见文末数据）——预期的「1.15→1.0 回弹」未出现，pill 停在约 1.07 倍直到页面重绘。
- **代码定位**：`assets/scripts/ui/CocosUi.ts` 314-320 `updateFlyItems` 的 pulses 循环：`p.elapsed += dt` 计算进度后**无条件 `CocosUi.pulses.splice(i, 1)`**——每条脉冲只更新一帧即被移除，仅当首帧 dt≥0.2s 才会顺带复位；否则节点停留在 1.15-0.15·t₀ 的中间尺度。0.2s 衰减动画实际从未播放。
- **影响**：每次领取后当前页面顶栏 pill 永久性轻微放大（帧间隙越大放大越明显，上限 1.15 倍），直到离开页面重绘；设计中的落地回弹观感缺失。campaign/journey/shop 三类页面均走此链路。
- **建议修法（供排期参考）**：`splice` 移入 `t >= 1` 分支（复位后再移除），即可恢复 0.2s 衰减并保证终态 scale=1。

## 六、方法学备注（后续走查复用）

- **存档注入的正确姿势**：须 `addInitScript` 同时补丁 `Storage.prototype.getItem` 与 `setItem`，且**注入后必须 reload 一次**——游戏 boot 时从 getItem 读入内存，之后一切状态以内存为准；只补丁 setItem 只改磁盘不改内存（本轮 `sup_box_shop2.js`、`sup_i5_v2.js` 两次无效均因此，`sup_i5_v3.js` 起修正）。与上轮「localStorage clear 后 onHide save() 会回写旧档」备注同源。
- **静帧法测短动效**：小区域 `clip` 截图帧距可压到约 33ms，但必须先估算动画窗口再设计帧偏移（I3 第一轮全落窗口前、第二轮全落窗口后，第三轮才罩住）；0.2s 级动效判定建议优先视频录制（本机无 ffmpeg，未采用）。
- **十连按钮坐标已变**：R5 重排后召唤页四按钮 x=-267/-89/89/267（`HeroScreens.ts` 431-437），旧脚本 [89,185] 现为元宝单抽——后续走查脚本需以当前源码坐标为准。
