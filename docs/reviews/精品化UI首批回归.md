# 精品化 UI 首批回归

日期：2026-10-04；执行者：Codex主agent统筹，三名子agent独立页面验证。状态：已实施待微信真机验收。

本批将主城、战役和招贤殿的几何占位换为原创场景，接入战斗立绘与背景；玩法入口改为四组滚区，英雄首屏保留两行卡，召唤四操作分出主次。修复万能卡弹层越框、广告/导航穿透、4星SSR被错误排除，以及战斗输出条遮住后排。六枚货币图标已生成并接入共用资源条，主城资源栏与五导航图标继续下一批。
