# 左右阵型与普攻动效回归

时间：2026-10-05；状态：已实施，待微信真机验收。

## 改动

- 战斗阵型改为左右相向的三前二后错列，直接显示全身英雄立绘；血条与怒气条置于头顶，名字在脚下，保留阵营、品质、阵亡、控制和满怒状态。
- 近战普攻沿战斗事件中的目标 UID 突进并回位；弓手、法师、辅助保持站位，沿用已有箭矢/法术弹道效果。受击抖动增强，数字从人物头顶弹出，血量与怒气条平滑变化，治疗保留绿色加血反馈。
- 满怒呼吸效果改为全身角色光环。原战场底图位于 `battles/` 子目录，已补入 ArtService 预载，进入战斗时可以显示城门战场背景。
- 规则、伤害、目标选择和存档均未改动；不复用竞品美术资源。战斗节奏参考 AFK Journey 的自动战斗与技能演出表达，资源保持本项目原创。

## 验证
