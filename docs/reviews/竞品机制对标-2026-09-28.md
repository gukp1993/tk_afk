# 竞品玩法机制对标报告（2026-09-28）

> 执行者：对标研究子代理（zcode 主会话派发）。调研对象：AFK Arena（对标原型）、微信小游戏爆款（咸鱼之王/寻道大千/疯狂骑士团）、放置卡牌通用惯例。实现建议已对照本仓库 `utils/config.js`、`utils/store.js`、`utils/items.js` 校准。

## 一、三类对象核心发现（摘要）

**AFK Arena**：留存支柱是"每日三件套 + 周常轮换"双节奏——悬赏栏（24h 刷新派遣）、异界迷宫（48h 重置的 roguelite 三选一）、快速收获；周常靠阵营塔按星期轮换开放（每周限 60 层）和 14 天一轮的奇境探险。升品狗粮体系制造 30 天级长线目标。

**微信小游戏爆款**：疯狂骑士团制作人访谈（GameLook）——"开箱是把 20 分钟副本的掉落压缩成一秒的爽感"；故意只做单开、不做 30 连开，把开箱节奏绑在升级节奏上；上线钓鱼这类低商业化副循环后 15/30 日留存显著提升。咸鱼之王 = 单点点击强反馈 + 宝箱五品质积分池 + 三国卡牌外循环 + 微信关系链排行榜（2024-02 MAU 1.17 亿）。

**通用惯例**：保底已成行业标配（原神 90 抽硬保底 + 约 74 抽软保底、4 星 10 抽必出）；离线收益惯用 12~24h 上限 + "欢迎回来"结算画面 + 广告翻倍；装备强化已从"失败归零"演进为"低级必成 + 失败充能补偿"，轻量玩家向游戏基本不做失败惩罚。

## 二、可借鉴机制（10 个，按 契合×低成本×感知强 排序）

### 1. 抽卡保底：十连必出 SR+ + 累计 N 抽必出 SSR
- 行业标配"10 连保底高档次 + 硬保底计数 + 软保底概率递增"。本项目 `GACHA` 完全无保底，是与行业惯例差距最大的一点。硬保底对应约 3~4 天元宝收入，与 30 天主线节奏匹配。
- 最小实现：`GACHA` 加 `pity`；`doSummonMutation` 维护 `state.summon.pity = { sinceSsr }`，十连末位全蓝白则补 SR，`sinceSsr >= N` 强制 SSR；`normalizeState` 补默认字段兼容旧档。约 40~60 行。
- 风险：SSR 供给率上升约一倍，需与难度联调重跑仿真。

### 2. 招募积分池（开箱积分 → 必得宝箱）
- 咸鱼之王每次开宝箱攒积分、积分满领额外宝箱；"必得感"是开箱循环核心。本项目已有同构的 `ACTIVE_CHESTS` 基础设施，可复制到招募：每次招募 +1 分，攒满 50/150/300 送 SSR 自选券碎片/招募令。
- 约 40 行。风险：与保底同时上线会叠加放大 SSR 供给，两者数值需一起核算。

### 3. 七日签到 / 新手七日目标树
- AFK Arena 七日签到：第 2 天紫卡、第 3 天十连、第 6 天六族十连、第 7 天紫卡+神话英雄。第 1 周是流失悬崖，签到是"每天上线一次"的 30 秒必得仪式；第 7 天大奖可复用 `ssrPick`。
- 最小实现：`SEVEN_DAY` 配置 + `state.sevenDay = { startDay, claimed }`（首登锚定）+ `claimSignIn()` + 弹层。约 70~90 行。
- 风险：纯签到可能变成"领完即走"，建议部分天数绑定轻行为（如"完成 1 场战斗可领"）。

### 4. 每日悬赏派遣（Bounty Board）
- AFK 悬赏栏：每 24h 刷新 6~14 个任务，星级 1~6 奖励递增，派英雄挂机几小时后领取。给"编外武将"（非主力 N/R 卡）一个就业场景，是比每日任务更轻的"派出去→明天来收"仪式。
- 最小实现：`BOUNTY` 配置 + `state.bounty = { day, list, slots }`，每日重置随机生成 4 个任务，`dispatchBounty/claimBounty` 两接口；约 100~120 行 + 屏内面板。
- 风险：与现有 6 条每日任务叠加成"作业变多"，任务数克制在 4 个以内。

### 5. 演武场每周段位结算奖励
- AFK 竞技场按段位周结算发钻石；小游戏用排行榜+周结算制造冲榜节奏。本项目 `ARENA_RANKS` 与 `ARENA.DAILY=5` 已在，但段位只是称号没有结算钩子。
- 约 40~60 行。风险：单人 AI 演武场冲榜压力有限，感知弱于真排行榜。

### 6. 集市神秘商人（限时折扣）
- AFK 异界迷宫流浪商人固定卖 4 件、第 4 件 6 折。集市目前是固定货架，加每日按日期种子刷新的 1~2 个 6~7 折商品，成本低且每天有新话题。
- 约 40~50 行。风险：折扣商品若含元宝直购招募令，注意与"单抽 100/十连 900"定价锚不冲突。

### 7. 阵营轮换试炼（对标阵营塔按星期开放）
- AFK 四座阵营塔按星期轮换开放，每周限 60 层，强制轮换培养各阵营。本项目有完整克制环与同阵营加成但阵容基本不动；"今日阵营试炼 Boss"（周一蜀、周二吴……只允许对应阵营上阵）能低成本制造周节奏。
- 约 80 行 + 入口。风险：前期玩家阵营池浅，限制阵营可能卡死，需"未达标可借 N/R 补位或降奖励"兜底。

### 8. 异界迷宫式 roguelite 三选一（48h~周重置）
- AFK 异界迷宫：3 层路线图，击败敌人后从遗物三稀有度选强化（可叠加），Boss 层给钻石，48h 重置。是"单次会话几分钟"的最优形态；遗物 buff（攻击+%、开场护盾、怒气）有现成字段可挂。
- 约 150~200 行；唯一动 `battle.js` 战斗核心的机制，需回归全部战斗用例。建议在其他项验证后实施。

### 9. 微信好友排行榜（开放数据域）
- 微信关系链好友榜是小游戏独有留存件；本项目演武积分、主线进度、塔层数都是天然可榜数据。
- 需开放数据域子域 + Cocos 子域渲染接入，属工程级改动；纯逻辑侧只需 `getLeaderboardScore()`。建议二期。

### 10. 离线收益"欢迎回来"结算呈现
- 行业惯例 12~24h 上限 + 回归可视化结算 + 广告翻倍钩子；本项目数值层已达标，缺的只是"回来拿一口"的仪式感。纯呈现层工作，规则层零改动。约 60 行 UI。

## 三、不建议照抄的机制

| 机制 | 为什么不抄 |
| --- | --- |
| AFK 大圣堂狗粮升品（吃同阵营卡升阶） | 已简化为"重复卡自动升星+满星转品质碎片"，对轻玩家更友好 |
| 装备强化失败/掉级/保护石 | 与"每天一次几分钟"定位相悖；轻量化游戏不做失败 |
| 公会狩猎 | 需要公会+好友基础设施，无社交底座 |
| 开服冲榜/全服排行榜 | 需服务器与运营节奏；周结算是低成本替代 |
| 3200 层主塔+1890 层阵营塔体量 | 群英塔无限层已够用，问题在奖励感知不在层数 |
