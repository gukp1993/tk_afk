## A. 演武名人堂（玩法页宽卡 → 名人堂页）

| # | 操作 | 预期 |
| --- | --- | --- |
| A1 | 玩法页名人堂宽卡 | 显示"已胜 x/3 · 荣耀 N"；与悬赏卡无重叠 |
| A2 | 名人堂页三席卡 | 席位/阵容名/五成员名/主将特质（有特质时红字"主将特质：…"）；本周已胜席位显示"已胜 ★N" |
| A3 | 挑战未胜席位 | 进入战斗，敌阵为该席五将、等级随我方战力 |
| A4 | 胜利结算 | 首杀：荣耀 +20 · 元宝 +50（一次性）；三星时追加"三星评价 +10 荣耀 · 碎片 +5"（分项数字正确，无负数） |
| A5 | 三席全胜 | 第三场结算含"周全胜！演武令 +10"；SSR 碎片 +5 入账 |
| A6 | 重复挑战已胜席位 | 正常战斗但结算显示"挑战成功（重复挑战不发奖）"；荣耀/元宝不变 |
| A7 | 荣耀过 100 / 300 | 名人堂页称号行显示已获「常胜将军」/「武圣传说」；只授一次 |
| A8 | 战报区 | 最近 5 场（席位/胜/负/★/时长）；点"回放"进入战斗页打【回放】标记，逐帧与原局一致，结算显示【回放】无奖励行 |

## B. 觉醒（英雄详情页，仅满 5★ SSR 显示）

| # | 操作 | 预期 |
| --- | --- | --- |
| B1 | 满星 SSR 详情页底部 | 觉醒面板：等级 x/3、下一级消耗（荣耀/SSR 碎片）、材料不足原因带来源指引 |
| B2 | 材料齐点击觉醒 | 荣耀与 SSR 碎片同扣、等级 +1；属性面板三维 +5%/级即时生效 |
| B3 | 连点觉醒至 3 级 | 显示"已达觉醒上限"；按钮不再消耗 |
| B4 | 觉醒扣荣耀后查名人堂 | 已授称号不被回收；荣耀数值减少不报错 |
| B5 | 未满 5★ SSR / 非 SSR 详情页 | 不显示觉醒面板 |

| --- | --- | --- |
